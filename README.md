# Professional Practice in IT — Student UI Concept

An **unofficial student-designed responsive interface concept** for the unit title *Professional Practice in IT* (SIT223 / SIT753). It is a portfolio exercise in HTML/CSS, not an official Deakin University website or unit guide.

## Features

- Semantic HTML with landmark regions and a heading hierarchy
- Clear navigation and keyboard-accessible skip link
- CSS Grid and responsive layouts for mobile and desktop
- Visible focus indicators and reduced-motion preference
- No JavaScript, external libraries or build tools

## Run

Open index.html directly in a web browser. All files are static.

## What changed

The original project was a page containing only a heading. This revision adds a full, responsive static layout while avoiding unverified official course information. The copy is illustrative, not real unit requirements.

## Review and next steps

Test keyboard navigation, mobile layouts, browser zoom and text contrast. Perform a formal accessibility audit and usability testing before using it for a real audience. GitHub Pages can publish the site if enabled by the repository owner.
